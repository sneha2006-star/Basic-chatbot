# Basic Chatbot

## Project Description
The Basic Chatbot is a simple rule-based chatbot developed using Python. It interacts with users by accepting text input and providing predefined responses based on the user's messages.

This project was developed as Task 4 of the CodeAlpha internship.

## Features
- Responds to greetings such as "hello".
- Answers "how are you" with a predefined response.
- Ends the conversation when the user types "bye".
- Displays a default response for unrecognized messages.
- Provides a simple command-line interface.

## Technologies Used
- Python

## Key Concepts Used
- Conditional Statements (if-elif-else)
- Functions
- While Loop
- User Input and Output
- String Handling
